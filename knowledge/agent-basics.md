# Agent 基础知识

AI Agent 是一个能围绕目标持续执行步骤的程序。它通常会接收用户问题、调用大语言模型，并根据需要使用工具。普通聊天程序可能只把问题发给模型；Agent 还可以根据模型返回的指令，继续调用工具并把结果交回模型。

一个简单 Agent 通常包含三个部分：入口负责接收用户输入；Agent Core 负责维护对话和安排执行；Model Provider 负责连接具体的大语言模型服务。把 Provider 抽象出来后，可以在不重写 Agent Core 的情况下替换模型服务。

RAG 的全称是 Retrieval-Augmented Generation，中文常译为“检索增强生成”。它先从外部知识库找出与问题相关的材料，再把材料和问题一起交给大语言模型。这样模型可以依据项目文档或企业知识回答，而不是只依赖训练时学到的知识。

RAG 的基础流程包括文档解析、文本分块、文本向量化、向量检索和答案生成。分块是把长文档拆成较小的文本片段；每个片段可以单独检索。分块过小可能丢失上下文，分块过大可能带入无关内容。
